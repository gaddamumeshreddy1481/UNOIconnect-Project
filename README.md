# UNOIconnect

UNOIconnect is a web application/API service designed to support
international student networking and community activities.

## Technologies

- Node.js
- Express.js
- MySQL
- Sequelize
- AWS RDS
- HTML
- CSS
- JavaScript

## Features

- User registration and authentication
- User management
- Event management
- REST APIs
- MySQL database integration

## Configuration

Database credentials are stored in environment variables using a `.env` file.

The `.env` file is intentionally excluded from Git using `.gitignore`.
